## ⚡ Quickstart Commands (Per Episode)

Clone the repository and immediately execute the blueprint for any specific episode:

### 🔹 Episode #001: Autonomous Agent Skills (Zero Cloud Cost)
```bash
# Clone the repository
git clone https://github.com/Johnmannen/Agentic-Stack-Library.git
cd Agentic-Stack-Library/001-autonomous-agent-skills

# Install dependencies and run
pip install -r requirements.txt
python agent_skill.py
```

### 🔹 Episode #002: ElevenLabs Real-Time Conversational Voice Agent
```bash
# Clone the repository (if not already cloned)
git clone https://github.com/Johnmannen/Agentic-Stack-Library.git
cd Agentic-Stack-Library/002-elevenlabs-voice-agent

# Install dependencies
pip install -r requirements.txt

# Run the voice agent
python voice_agent.py
```
