## 🧠 What You Build in Episode #008
1. **Zero-Cost Cloud Brain + Local Python Hands:** Pairs Google Antigravity with lightweight local Python tools and free-tier APIs (Gemini, Groq, OpenRouter, NVIDIA) — runs smoothly on older dual-core PCs with zero GPU.
2. **Global Safety Guardrails:** `AGENTS.md`, `hooks.json`, `post_edit_verify.py`, and `safe_exec.py` keep local automation fast and safe.
3. **3-Layer Persistent Memory & Write Gate:** Auto-learns user facts, blocks leaked API keys/secrets automatically, and enforces `stage` → `approve` on major changes.
4. **9 Specialist Subagents:** `juno-builder`, `disk-librarian`, `win10-expert`, `chrome-visual-agent`, `qa-auditor`, and more.
5. **One-Command Project Scaling:** `init_project.py --stack <web|python|mobile|general>` bootstraps clean local rules for any new workspace.
6. **Hands-Free Live Voice Mode & Dictation:** Two-way Gemini Live pair-programming + `Ctrl+M` Speech-to-Text dictation inside Antigravity Desktop.
7. **Mobile Remote Control:** Trigger tasks from your phone (`antigravity.google.com` PWA) and watch your home desktop execute live.
8. **Vibe-Coding & Clean Public Export:** Customize in plain English and export sanitized public templates via `export_public_template.py`.
